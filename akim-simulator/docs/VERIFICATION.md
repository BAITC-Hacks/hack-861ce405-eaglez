Снимки `preview-desktop.png` и `preview-mobile.png` проверены визуально. Скриншоты показывают локальный режим, не подключённую модель.

Для повторения браузерного теста необязательную тестовую зависимость можно установить отдельно:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/browser-smoke.cjs
```

Само приложение и `npm test` не требуют Playwright. В проверочной среде он установлен вне папки приложения. Browser smoke сам запускает и закрывает временный сервер.
