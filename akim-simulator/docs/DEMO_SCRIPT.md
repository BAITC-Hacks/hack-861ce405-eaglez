# Демонстрация за три минуты

1. «Мы показываем компромисс между средним качеством жизни, слабейшим районом и критическими провалами при ограниченном бюджете».
2. Открыть страницу: база 52,56, две критические ячейки в Нуре. Показать график районов.
3. Нажать «Пример задания»: стоимость 95, Score 56,54, критических значений нет. Раскрыть формулу.
4. Сбросить, добавить M1, попытаться добавить M3: показать объяснение несовместимости. Вернуться к примеру.
5. Сохранить пример. Показать замену M5(Сарыарка) на M3(Нура): Score 57,21, стоимость 100. Применить, сохранить второй вариант, сравнить.
6. Обсудить компромисс: улучшение транспорта Нуры вместо экологического проекта Сарыарки. Рост Score не означает, что исчезли все городские проблемы.
7. Нажать AI-разбор. При подключённом API показать реальную метку провайдера: «Модель выбирает существенные аргументы из проверенного расчёта». В offline-режиме честно назвать объяснение локальным.
8. Задать вопрос «Что произошло с Нурой?» и показать соответствующие цифры. Показать README и npm test, объяснить разделение интерфейса, модели расчёта и внешнего API.

Не заявлять реальный городской прогноз, глобальную оптимальность или проверенное внешнее подключение при показе fallback.
