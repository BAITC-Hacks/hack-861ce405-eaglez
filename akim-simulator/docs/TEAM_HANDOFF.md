# Передача проекта команде

## Дизайн

Передать участнику папку public/. Цвета, карточки и адаптивная сетка — styles.css; структура — index.html. JavaScript опирается на ID элементов: сохраняйте их при переделке структуры или обновляйте селекторы вместе с HTML. Расчёт остаётся на сервере.

После изменения интерфейса выполните `python3 scripts/build-standalone.py` и замените файл для быстрой демонстрации `dist/akim-standalone.html`. Это один собираемый результат, не отдельная вторая версия логики.

Есть светлый интерфейс с тёмной панелью Score, фильтрами, карточками мер и графиками. На узком экране колонки перестраиваются. Шрифты системные, внешние картинки/CDN не нужны. Шкала графиков единая: 0–100. Синтетические районы не выдаются за географическую карту.

Проверить ноутбук 1366×768, мобильный экран 390 px, управление клавиатурой, длинные названия, сообщения валидатора и ожидание AI. Не путать исходный балл с оценкой незавершённого плана: неполный план не оценивается.

## API и ИИ

Ключи только на сервере в .env. OpenAI и NVIDIA — альтернативные способы получения ответа; они не вызываются вместе. Model ID задаёт владелец API-доступа. Реальный ключ, модель и квоту перед защитой проверяет команда.

Запрос к провайдеру происходит только при нажатии «Разобрать сценарий». Подбор мер и рекомендации не расходуют API-кредиты. Успешный ответ кэшируется на время работы сервера. Содержимое тестов AI — имитация, не доказательство доступа к живой модели.

LLM сейчас выбирает аргументы из каталога проверенных фактов, в том числе в ответ на вопрос пользователя. Свободное объяснение произвольного вопроса не предусмотрено: ответы на вопросы вне имеющихся данных могут быть общими. Если расширять до свободного диалога, понадобятся проверка чисел и оценка галлюцинаций. Ограничение текущего варианта явно описано в README.

## Распределение ролей

| Роль | Задача |
|---|---|
| Владелец модели | Данные, формула, валидатор, понимание результатов и рекомендаций |
| Frontend | public/, дизайн и поведение интерфейса |
| API-интеграция | Свой .env, реальный успешный запрос, проверка квоты и ошибок |
| Репозиторий/демо | GitHub, тесты, воспроизводимость, репетиция |

## Дальнейшее размещение

Текущая поставка локальная. Для публичного сайта нужны работающий backend, HTTPS, вход участников, ограничения AI-расхода и общая база сценариев. Обычная статическая публикация HTML не запускает Node.js. Публичный сайт сейчас не развёрнут.

Данные условные. Шепли распределяет результат формулы, не доказывает причинность. Поиск ограничен одной заменой, глобальный оптимум не заявляется. События и рейтинг команд пока не реализованы: это дополнительные правила и инфраструктура.
