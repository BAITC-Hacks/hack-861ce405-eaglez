# Что куда подключать — без тумана

Проект — обычная папка с кодом. Чтобы прямо сейчас увидеть рабочую страницу, скачай `akim-standalone.html` и дважды щёлкни по нему: откроется браузер. Установка и запуск сервера для этой демонстрации не нужны. Для живого ИИ позже понадобится Node.js, API-доступ и интернет. Новую нейросеть обучать и покупать видеокарту не требуется.

## Кто за что отвечает

| Название | Простыми словами | В проекте |
|---|---|---|
| Frontend | То, что видит и нажимает пользователь | Файлы в public/ |
| Backend / сервер | Программа, принимающая запросы | server.js на твоём компьютере |
| API | Адрес и правила обмена данными между программами | Браузер отправляет пять решений в /api/analyze |
| API-ключ | Секретный пропуск к сервису и его балансу | Строка в .env, доступная серверу |
| Модель | Готовый ИИ для обработки запроса | Текстовая модель выбранного провайдера |
| GitHub | Общая папка с историей изменений и доступом команды | Будущий репозиторий проекта |
| Codex | Помощник, который читает, пишет и проверяет код | В редакторе или в облаке |
| NVIDIA | Компания и набор разных AI-сервисов | Здесь поддержан её hosted API Catalog |

Сервер не обязательно отдельная «машина». После `npm start` твой ноутбук выполняет его роль. localhost:3000 — адрес на этом же компьютере; интернет-сайт автоматически не появляется.

API похоже на вызов функции: отправляешь аргументы, получаешь результат. Только они передаются по HTTP. Наш сервер получает список мер, вызывает analyze() и возвращает JSON. При разборе ИИ сервер дополнительно отправляет проверенные факты внешней модели.

## Запуск полной версии с живым ИИ на Windows

1. Установи Node.js LTS: https://nodejs.org/en/download.
2. Распакуй архив. Найди папку, в которой лежат package.json и server.js.
3. Открой её в редакторе и открой терминал. Или в Проводнике выбери «Открыть в терминале» для этой папки.
4. Проверь `node --version`: нужна версия 22 или новее. Если команда неизвестна, перезапусти терминал после установки.
5. Выполни `npm start`. Терминал должен оставаться открытым.
6. Открой http://localhost:3000. Нажми «Пример задания»: Score 56,54.
7. Нажми «Разобрать сценарий». Без API-ключа появится локальный разбор с соответствующей подписью.

Если PowerShell блокирует npm.ps1, используй `npm.cmd start` или `node server.js`; менять политику PowerShell не нужно. Тесты: `npm.cmd test`.

## Куда вставить API-ключ

В терминале папки проекта:

```powershell
Copy-Item .env.example .env
```

Открой .env в редакторе. Это обычный текстовый файл рядом с server.js. Название должно быть .env, не .env.txt. Заполни три строки для выбранного провайдера по README и перезапусти сервер.

Ключ не вставляется в HTML, браузерный JavaScript, README, чат или скриншот. .gitignore уже исключает .env из обычного git add. .env.example содержит пустые поля и может лежать на GitHub.

Где получить: OpenAI API — https://platform.openai.com/api-keys. NVIDIA Catalog — https://build.nvidia.com/settings/api-keys. Имя модели берётся из её примера API; это не название твоей подписки. Если нет доступа, сначала выясни, что именно выдали организаторы.

Метка в шапке «настроен, не проверен» не подтверждает работу ключа. Настоящее подключение подтверждает успешный разбор с подписью ИИ и именем провайдера/модели.

## Что могут означать выданные кредиты

- **Codex / ChatGPT credits**: оплачивают помощь в написании кода.
- **OpenAI API credits**: баланс запросов вашего приложения к OpenAI; важно выбрать проект/организацию, куда выдан баланс.
- **NVIDIA API Catalog / hosted NIM API**: доступ к модели у NVIDIA через API. Этот вариант поддерживает наш код.
- **GPU hours / DGX / облачная машина**: вычислительные ресурсы для собственного запуска моделей, другой путь настройки.
- **DLI / курс / сертификат**: обучение, а не обязательно ключ к модели.

Это ориентиры, а не утверждение о конкретной выдаче вашей команде. Нужен документ или скриншот названия доступа без секретов. Не нужно тратить все баллы ради использования всех логотипов.

## Codex: два способа

**В редакторе.** Установите официальное расширение Codex в поддерживаемый редактор, например VS Code. Войдите в аккаунт с выданным доступом и откройте папку проекта. GitHub для работы с локальной папкой заранее не обязателен.

**В браузере.** Откройте https://chatgpt.com/codex. Подключите GitHub, выберите репозиторий и создайте окружение. Окружение — папка проекта и настройки запуска в облаке. После этого задавайте задачи.

В проекте есть AGENTS.md с архитектурой и правилами. Давайте Codex небольшие проверяемые задания: изменить конкретный экран, сохранить API-контракт и формулу, запустить npm test, показать изменения. Читайте результат перед объединением с кодом команды.

Codex помогает разработке. В работающем сайте кнопку советника обслуживает API выбранной модели, а не редактор кода.

## GitHub

Удалённый репозиторий ещё не создан. Его создаёт участник в аккаунте команды.

Через сайт: создать репозиторий → Add file → Upload files → загрузить содержимое папки проекта. Не загружайте один ZIP вместо исходников и не загружайте секретный .env. Включите .gitignore, .env.example, AGENTS.md и .github/workflows/tests.yml; Проводник может скрывать файлы с точкой.

Для постоянной совместной работы используйте Git. После установки Git, в папке проекта:

```sh
git init
git add .
git status
git commit -m "Build city simulator with validated scoring and AI adapters"
git branch -M main
```

Создайте пустой репозиторий на GitHub и возьмите его HTTPS-адрес. Пример ниже замените своим:

```sh
git remote add origin https://github.com/YOUR_ACCOUNT/akim-simulator.git
git push -u origin main
```

Если Git просит имя/почту, задайте свои через git config user.name и git config user.email. Вход выполняется штатным способом Git или редактора. GitHub хранит код: загрузка репозитория сама по себе не запускает сервер и не оплачивает API.
