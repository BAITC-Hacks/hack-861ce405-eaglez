# «Аким на 5 часов» — прототип симулятора

Рабочий автономный прототип по условиям Astana Innovations. Все данные синтетические. Интерфейс на русском, без сервера и внешних пакетов.

## Запуск

Откройте `index.html` в браузере. Для проверки расчётов установите Node.js и выполните `node test.js` из папки проекта. Интернет и API-ключ для этого прототипа не нужны. Не открывайте `app.js` отдельно: он подключён в HTML после `engine.js`.

## Сценарий демо

1. Нажмите «Пример из задания»: пять решений общей стоимостью 95.
2. Убедитесь, что Score равен 56,54, а база 52,56. Посмотрите на таблицу районов и эффект синергии M10+M12.
3. Нажмите «Набор за 61», сравните результат. Сохраните оба сценария и переключайтесь между ними.
4. Попробуйте выбрать шестую меру, повтор, превышение бюджета или несовместимые M1+M3: валидатор возвращает причину.

## Архитектура

- `engine.js`: исходные данные, правила, лаги, эффекты, синергии, clip, Score. Единственный источник чисел.
- `app.js`: выбор, сообщения о нарушениях, сравнение сценариев, таблица изменений и шаблон объяснения.
- `index.html`: визуальный интерфейс. `test.js`: проверки эталона и ключевых ограничений.

Для каждой меры эффект масштабируется `(8-L)/8`, синергия добавляется без масштабирования. Потом значения ограничиваются диапазоном 0–100. Score = `0.7 × взвешенный по населению балл + 0.3 × минимум районов − число показателей строго ниже 40`. Неполный или невалидный сценарий Score не имеет. Веса и исходные значения взяты из текста кейса.

Проверка: база = 52.55768; пример M7(Нура), M8(Нура), M10(Нура), M12(город), M5(Сарыарка) = 56.54307, прирост 3.98539. Точность округления интерфейса — 2 знака.

## Как подключить OpenAI / NVIDIA

Это следующая интеграция команды; API пока не подключён. Создайте серверный endpoint, который принимает только результат `calculate(choices)` и перечень выбранных мер. Ключ храните в переменной окружения сервера, не в `index.html` и не в клиентском JavaScript. Сервер обращается к выбранной LLM и возвращает объяснение. Если сервис недоступен, оставьте шаблонное объяснение.

Пример инструкции модели: «Ты объясняешь городской сценарий. Используй исключительно переданный JSON. Не пересчитывай Score, не добавляй цифр, которых нет в JSON. Кратко назови сильные стороны, слабейший район, критические показатели и один компромисс. Это синтетическая модель, не прогноз для реальной Астаны». Передавайте `score`, `average`, `minimum`, `critical`, `rows`, `contributions`, `cost`; возвращаемый текст помечайте как пояснение ИИ. Проверяйте, что числа в ответе соответствуют JSON, или вообще запрещайте модели писать числа и добавляйте их шаблоном.

NVIDIA может служить инфраструктурой запуска модели, если это требуется правилами хакатона; сам математический Score от выбора провайдера не зависит. Конкретные требования по OpenAI/NVIDIA и оборудованию проверяйте в приложенных организаторами документах перед интеграцией.

Ограничения: сравнения сохраняются лишь до перезагрузки страницы; рекомендации пока шаблонные; предсказаний для настоящих районов или подтверждённой эффективности реальных проектов нет.
