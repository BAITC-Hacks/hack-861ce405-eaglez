# AI-советник

## Запуск
Требуется Node.js 22 или новее. Внешних npm-зависимостей нет.

1. Скопируйте `.env.example` в `.env`.
2. Локально заполните `OPENAI_API_KEY` и `OPENAI_MODEL`: ID доступной вашему API-проекту модели с поддержкой Responses API и function calling. Ключ не вставляйте в браузер или переписку.
3. Из папки проекта выполните `npm start` (или `node --env-file=.env server.js`).
4. Откройте http://127.0.0.1:3000, выберите пять допустимых решений и нажмите «Проанализировать с ИИ».

Без ключа или при ошибке API расчёт и шаблонное объяснение работают. Открытие index.html напрямую сохраняет прежний автономный режим, но ИИ требует сервера. Запросы к OpenAI могут тарифицироваться вашим API-проектом.

## Как устроен агент
Браузер передаёт только решения. Сервер проверяет их и пересчитывает через engine.js.
Responses API вызывает инструменты:
- find_improvements: перебор допустимых замен одной меры или её района; до трёх улучшений Score.
- evaluate_scenario: проверка и расчёт предложенного моделью набора.

Результаты инструментов возвращаются модели, которая объясняет сильные стороны, риски и компромиссы. До пяти запросов к модели на анализ, таймаут каждого — 45 секунд. Сервер обрабатывает один анализ одновременно. Карточки содержат рассчитанные сервером показатели; пользователь применяет вариант кнопкой. Это поиск локальных улучшений, не доказательство глобального оптимума.

## Проверки
`npm test` запускает исходные тесты ядра и тесты инструментария, агентного цикла с имитацией API, ошибок и HTTP endpoint. Эти тесты не доказывают качество ответов реальной модели. Для живой проверки настройте ключ и модель, загрузите пример и запросите анализ; сравните карточку рекомендации с итогом после её применения.

## Ограничения
Текст модели может содержать ошибки: численные утверждения в прозе не проходят автоматическую проверку. Карточки рекомендаций формируются только из проверенных расчётов. Расчётная модель синтетическая; это не прогноз для реальной Астаны. NVIDIA не интегрирована; соответствие отдельному документу организаторов не проверено.

Сервер предназначен для локальной демонстрации и слушает только 127.0.0.1. Для публичного размещения нужны аутентификация и ограничения расходов. Ключ хранится на сервере в окружении; .env не раздаётся HTTP-сервером и исключён из Git.

Документация: https://developers.openai.com/api/docs/guides/function-calling
