# «Аким на 5 часов» - интерактивный симулятор распределения городского бюджета с проверенными рекомендациями, работающий на основе искусственного интеллекта.
## 2. Краткое описание
Это решение помогает принимать управленческие решения в условиях ограниченного бюджета. Управляющему городом, аналитику или участнику симулятора нужно распределить 100 условных единиц между пятью направлениями:
- Транспорт
- Озеленение
- Социальная инфраструктура
- Безопасность
- Городские услуги
- 
В результате видны, как воздействуют выбранные меры на показатели пяти условных районов, как рассчитывается *Astana Quality of Life Score* (оценка качества жизни в Астане), какие плюсы и минусы есть у разных сценариев. Консультирующий ИИ проверяет альтернативы тем же расчетным ядром и предлагает только обоснованные улучшения.
Целевая аудитория: организаторы и жюри хакатонов, городские аналитики, студенты и все, кто интересуется принятием решений на основе данных.

## 3. Реализованные функции
- Выбор ровно пяти мероприятий из каталога из 14 мер.
- Бюджет в 100 единиц с автоматическим контролем превышения.
- Валидация всех правил: повторения, района, направления, несоответствия, ровно пять решений.
- Расчет эффектов с учетом лага (8 - L) / 8.
- Три синергии: M1+M2, M10+M12, M5+M6.
- Три несоответствия: M1+M3, M4+M7, M5+M13.
- Штраф за критические показатели строго ниже 40.
- Astana Quality of Life Score:
  `0.7 × средневзвешенный балл + 0.3 × минимум районов − штраф`.
- Шаблонное объяснение результата без ИИ.
- AI-советник на OpenAI Responses API с function calling.
- Проверяемые рекомендации: карточки формируются только из расчётов серверного ядра.
- Сохранение и сравнение нескольких сценариев в рамках сессии.
- Таблица изменений по районам и вклада каждой меры.
- HTTP-сервер для локального запуска ИИ.
- Тесты ядра, агента и HTTP endpoint.
- Адаптивный интерфейс на русском языке.

## 4. Как работает решение
1. Пользователь открывает интерфейс, выбирает мероприятие и район, добавляет решение.
2. Система проверяет правила: бюджет, всего пять мер, повторение, направление, несоответствие.
3. После нахождения пяти допустимых решений ядро `engine.js` рассчитывает показатели для каждого района.
4. Интерфейс показывает балл (Score), сравнение с значением из базы, самый слабый район, критические показатели и вклад каждой меры.
5. При нажатии на кнопку «Проанализировать с ИИ» передается на сервер список решений.
6. Сервер проверяет данные, переходит к сценарию через `engine.js` и вызывает OpenAI Responses API.
7. Модель использует следующие инструменты:
   - `find_improvements` - перебирает возможные замены одной меры или района;
   - `evaluate_scenario` - проверяет предлагаемый набор мер.
8. Все результаты инструментов передаются модели, она формирует объяснение.
9. Пользователь видит проверенные рекомендации и может применить их одним нажатием кнопки.

## 5. Технологии

- **Node.js 22+** - серверная среда без внешних зависимостей npm.
- **JavaScript (ES2022)** - логика как на клиенте так и на сервере.
- **HTML5 и CSS3** - интерфейс без использования фреймворков.
- **OpenAI Responses API** - анализ с помощью ИИ и вызов функций.
- **Модель** - любая модель API, совместимая с OpenAI Responses API и вызовом функций, указанная в переменной `OPENAI_MODEL`.
- **Node.js test runner** — тесты.
- **HTTP-сервер Node.js** — раздача статики и endpoint `/api/analyze`.

## 7. Установка и запуск

Требуется Node.js 22 или новее. Внешние npm-пакеты не нужны.

### Автономный режим без ИИ
```bash
git clone <ссылка-на-репозиторий>
cd akim-simulator
node test.js
```
Откройте `index.html` в браузере. Расчёт и шаблонное объяснение работают без сервера и ключа.

### Режим с AI-советником
1. Скопируйте `.env.example` в `.env`.
2. Заполните:
```
OPENAI_API_KEY=ваш-ключ
OPENAI_MODEL=модель-с-поддержкой-Responses-и-function-calling
PORT=3000
```

3. Запустите:
```bash
npm start
```
или
```bash
node --env-file=.env server.js
```

4. Откройте http://127.0.0.1:3000.

Ключ хранится только на сервере. Не вставляйте его в браузер, клиентский JavaScript или переписку.
## 8. Как проверить решение

### Проверка расчёта
```bash
node test.js
```
Ожидаемый результат: база около `52.56`, пример из задания около `56.54`, прирост около `3.99`.

### Полный цикл в интерфейсе
1. Откройте http://127.0.0.1:3000.
2. Нажмите «Пример из задания».
3. Убедитесь, что Score около `56.54`, стоимость `95`, синергия `M10+M12` сработала.
4. Нажмите «Проанализировать с ИИ».
5. Сравните карточку рекомендации с итогом после её применения.
6. Нажмите «Набор за 61» и сравните сценарии.
7. Попробуйте нарушить правила: шестая мера, повтор, превышение бюджета, `M1+M3`, `M4+M7` в одном районе, `M5+M13` в одном районе.

### Тесты агента и HTTP
```bash
node --test agent.test.js
```
Проверяются: отклонение некорректных данных, валидность рекомендаций, агентный цикл с имитацией API, лимит шагов, HTTP endpoint и запрет выдачи служебных файлов.

## 9. Данные и интеграции

- Синтетический датасет пяти районов: Есиль, Алматы, Сарыарка, Байконур, Нура.
- 10 показателей: `T1`, `T2`, `E1`, `E2`, `S1`, `S2`, `B1`, `B2`, `C1`, `C2`.
- Веса показателей из задания.
- 14 мероприятий с типом, стоимостью, лагом и эффектами.
- 3 синергии и 3 несовместимости.
- OpenAI Responses API — единственная внешняя интеграция, включается только при наличии ключа и модели.
- NVIDIA не интегрирована; соответствие отдельному документу организаторов не проверено.

## 10. Ограничения

- Численные утверждения в тексте модели не проходят автоматическую проверку. Карточки рекомендаций формируются только из проверенных расчётов.
- Расчётная модель синтетическая и не является прогнозом для реальной Астаны.
- Поиск улучшений локальный: перебираются замены одной меры или её района, это не доказательство глобального оптимума.
- Сервер обрабатывает один анализ одновременно.
- До пяти запросов к модели на анализ, таймаут каждого 45 секунд.
- Сохранённые сценарии живут до перезагрузки страницы.
- Сервер слушает только `127.0.0.1` и предназначен для локальной демонстрации.
- Для публичного размещения нужны аутентификация и ограничения расходов.
- NVIDIA и внешние городские API не подключены.
