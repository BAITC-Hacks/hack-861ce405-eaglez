# hack-861ce405-eaglez
Hackathon team repository for EagleZ
Astana Innovations «Аким на 5 часов»
Рабочий автономный прототип по условиям Astana Innovations. Все данные синтетические. Интерфейс без сервера и внешних пакетов.

Запуск
Откройте `index.html` в браузере. Для проверки расчётов установите Node.js и выполните `node test.js` из папки проекта. Интернет и API-ключ для этого прототипа не нужны. Не открывайте `app.js` отдельно: он подключён в HTML после `engine.js`.

## Сценарий
1. Нажмите «Пример из задания»: пять решений общей стоимостью 95.
2. Убедитесь, что Score равен 56,54, а база 52,56. Посмотрите на таблицу районов и эффект синергии M10+M12.
3. Нажмите «Набор за 61», сравните результат. Сохраните оба сценария и переключайтесь между ними.
4. Попробуйте выбрать шестую меру, повтор, превышение бюджета или несовместимые M1+M3: валидатор возвращает причину.

## Архитектура
- `engine.js`: исходные данные, правила, лаги, эффекты, синергии, clip, Score. Единственный источник чисел.
- `app.js`: выбор, сообщения о нарушениях, сравнение сценариев, таблица изменений и шаблон объяснения.
- `index.html`: визуальный интерфейс. `test.js`: проверки эталона и ключевых ограничений.
Для каждой меры эффект масштабируется `(8-L)/8`, синергия добавляется без масштабирования. Потом значения ограничиваются диапазоном 0–100. Score = `0.7 × взвешенный по населению балл + 0.3 × минимум районов − число показателей строго ниже 40`. Неполный или невалидный сценарий Score не имеет. Веса и исходные значения взяты из текста кейса.

Проверка: база = 52.55768; пример M7(Нура), M8(Нура), M10(Нура), M12(город), M5(Сарыарка) = 56.54307, прирост 3.98539. Точность округления интерфейса — 2 знака.
